# 공모전 데모 스크립트

## 3분 버전

1. `python -m streamlit run app.py`로 앱을 열고 왼쪽 `전체 오프라인 데모 실행`을
   누릅니다.
2. Stage 0에서 “모델 confidence를 믿지 않고 원문 evidence와 규칙 검증을 쓴다”고
   설명합니다. 통화·금액·결제일 3개 확인 전 gate가 잠겨 있음을 보여줍니다.
3. Stage 1에서 7개 값을 “예측이 아닌 수동 스트레스”라고 강조합니다. 팀원 JSON이나
   endpoint도 같은 schema로 연결됨을 보여줍니다.
4. Stage 2에서 open exposure와 실제 총 현금결제를 구분하고, 환율별 원화금액,
   날짜별 잔고 차트, buffer/cash/credit 부족의 차이를 보여줍니다.
5. Stage 3에서 비율 합계 100%인 후보 3개가 확정 자문이 아님을 설명합니다.
6. Stage 4에서 공식 URL과 `unknown/상담 필요` 표시를 보여줍니다.
7. Stage 5에서 핵심 숫자의 `[source: JSON.path]`와 결정론 fallback을 보여주고
   JSON·Markdown을 다운로드합니다.

## 심사위원에게 강조할 문장

- “파인튜닝부터 하지 않고 정답셋·Few-shot·validator·평가로 실패 원인을 먼저
  측정합니다.”
- “LLM이 숫자를 계산하지 않으며 사용자 확인값만 Decimal 엔진에 들어갑니다.”
- “기존 헤지는 위험노출에서는 빠지지만 실제 현금결제에서는 사라지지 않습니다.”
- “확률이 없는 스트레스에는 기대값과 부족확률을 만들지 않습니다.”
- “상품은 공식 출처 후보이고 자격·승인·금리는 기관 상담으로 넘깁니다.”

## 실제 API 시연

키가 설정된 경우 실제 API 모드를 선택하고 한 문서만 호출합니다. 실패에 대비해
offline 데모를 먼저 열어 둡니다. 실제 문서에는 개인정보가 없거나 시연 허가가 있는
자료만 사용합니다.
