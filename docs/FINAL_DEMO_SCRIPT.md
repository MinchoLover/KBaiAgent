# 최종 데모 스크립트

목표 시간은 6분이며 모든 입력은 합성 Golden 자산을 사용한다. 발표 전 live 기능을
끄고 file forecast와 사용자 확인 기준환율 1,400원을 사용하는 API-free 경로를
확인한다.

## 0:00~0:40 — 문제와 원칙

멘트:

> 수출입 기업은 환율 숫자만이 아니라 이번 계약에서 원화 현금이 얼마나 달라지고,
> 무엇을 은행과 먼저 상담해야 하는지 알아야 합니다. KBaiAgent는 AI가 읽고,
> 코드는 계산하고, 사람은 확인하고, KB가 결정하도록 책임을 분리했습니다.

클릭:

1. `Golden 수출거래`를 시작한다.
2. `거래 분석` 탭을 연다.

## 0:40~1:35 — 거래 분석

보여줄 값:

- 한국 판매자 → 브라질 구매자, 수출, USD
- 분석 대상 예정 수취 노출 USD 100,000
- 계약상 잔금 USD 80,000
- 결제 예정일 2026-08-20
- Open Account / T/T
- 선지급 USD 20,000의 실제 입금 여부는 `UNKNOWN`

멘트:

> 계약서에 적힌 예정 노출과 실제 현재 미수잔액을 구분합니다. 선지급 조건만으로
> 이미 입금됐다고 추측하지 않고, 사용자가 원문과 대조한 뒤에만 계산을 시작합니다.

## 1:35~2:45 — 환율 전망·위험

클릭:

1. `환율 전망·위험` 탭을 연다.
2. AI 전망 hero와 범위 차트를 보여준다.
3. `환율 전망 관련 시장 배경`과 현금흐름 결과를 차례로 보여준다.

보여줄 값:

- 기준환율 1,400원
- 모델 중심 1,386원, -1.0%
- 예측 범위 1,349.60~1,449.00원
- 모델 기간 2026-08-02~2026-08-25
- 고정 -5% 스트레스 수취액 133,000,000원
- 기준 대비 감소 7,000,000원
- 스트레스 후 현금 8,000,000원, 버퍼 부족 2,000,000원
- 현금 적자와 신용한도 반영 후 부족은 각각 0원

멘트:

> 모델 전망과 고정 스트레스를 분리합니다. 뉴스는 수치를 계산하지 않고 전망을
> 이해하는 시장 배경으로만 표시합니다. 결제일이 모델 범위를 벗어나면 모델 중심값을
> 현금흐름에 외삽하지 않습니다.

## 2:45~3:50 — Golden 금융지원 추천

클릭:

1. `금융지원 추천` 탭을 연다.
2. Golden Top 3를 위에서 아래로 보여준다.

순서:

1. 단기수출보험 검토
2. KB Star FX 선물환·외환스왑 상담
3. 환변동보험 검토

멘트:

> 추천은 가입·승인이 아니라 상담 순서입니다. 공식 catalogue의 활성 항목만 들어오고,
> 자격·한도·적용환율·보험료는 기관 심사 전 확정하지 않습니다.

## 3:50~4:40 — 조건에 따라 바뀌는 후보와 모순 차단

Demo D 입력:

- 선적 전, 채권 미발생
- 제조자금, 은행 금융 의사 있음
- 중소기업 확인, 연간 수출 USD 100,000 이상
- 해외시장 진출·정책금융·생산/운전자금 필요 있음

한 번의 `선택 내용 반영해 추천 업데이트`로 다음 순서를 보여준다.

1. 수출신용보증(선적전)
2. 신시장진출지원자금
3. KB Star FX 선물환·외환스왑

이어서 Demo E 캡처 또는 화면으로 `채권 미발생 + 채권매입 의사`를 입력하면 추천을
중단하고, 선적 전 통관 완료와 신용정보 부족·조사 거절은 재확인 경고로 분리하는 것을
보여준다. 이전 추천 카드가 남아 있지 않은지 확인한다.

## 4:40~5:35 — 상담 준비·보고서

클릭:

1. Golden 상태로 돌아온다.
2. `상담 준비·보고서` 탭을 연다.
3. 상담 순서, 기관 질문, 준비자료, 공식 후보 순서를 보여준다.
4. `상담 준비서 다운로드` 버튼을 가리키되 실제 RM 전송·예약으로 설명하지 않는다.

멘트:

> 화면과 다운로드는 같은 최신 ConsultationPacket에서 파생됩니다. 거래나 후보 입력이
> 바뀌면 이전 Packet과 보고서를 사용할 수 없고 다시 생성해야 합니다. LLM이
> unavailable이어도 숫자와 순서를 고정한 결정론 보고서로 완주합니다.

## 5:35~6:00 — 마무리

> KBaiAgent는 금융 결정을 자동화하지 않습니다. 확인된 거래 사실을 재현 가능한
> 숫자와 설명 가능한 상담 행동으로 바꾸어, 기업과 KB가 같은 사실 위에서 더 빨리
> 대화를 시작하게 합니다.

## 예상 질문

- **왜 USD 100,000을 분석합니까?** 계약상 예정 수취 노출이며 실제 미수잔액은
  입금내역 확인 전 알 수 없습니다.
- **왜 버퍼 부족이 있는데 대출을 추천하지 않습니까?** 현금 적자와 신용 후 부족이
  모두 0원이므로 200만원은 목표 버퍼 차이이지 필요 대출액이 아닙니다.
- **뉴스가 예측을 만듭니까?** 아닙니다. 저장된 시장 배경이며 숫자를 변경하지 않습니다.
- **상품 가입이 가능한가요?** 서비스는 상담 후보만 제시하며 실제 자격·가격·승인은
  은행·K-SURE·중진공 확인이 필요합니다.

## 외부 서비스 장애 시 대체 동선

- 관세청 unavailable: 무역통계 empty state를 짧게 보여주고 계약·환율·현금 결과로
  계속 진행한다.
- 뉴스 unavailable: 정상 empty state를 보여주고 전망 hero를 유지한다.
- Stage1 HTTP unavailable: 저장된 file forecast와 사용자 확인 기준환율을 사용한다.
- Stage5 LLM unavailable: 결정론 보고서를 생성한다.
- 장애를 live 성공처럼 말하지 않고 provider 상세나 stack trace도 화면에 노출하지
  않는다.
