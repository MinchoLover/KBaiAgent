# Codex 범용 오류 자동수정 프롬프트

현재 앱이 오류를 내고 있다. 추측으로 한 줄만 바꾸지 말고 재현 가능한 디버깅 절차로 해결하라.

1. 사용자가 보고한 오류와 현재 코드 상태를 읽는다.
2. 동일 명령으로 오류를 직접 재현한다.
3. 전체 traceback에서 최초 원인과 2차 증상을 분리한다.
4. Python/SDK/Pydantic/Streamlit 버전과 API 사용법을 확인한다.
5. 최소 수정으로 root cause를 고친다.
6. 해당 오류를 재현하는 회귀테스트를 추가한다.
7. 관련 모듈 테스트 후 전체 테스트와 `scripts/verify.py`를 실행한다.
8. Python 3.9 호환성을 확인한다.
9. 기존 기능이 깨졌는지 sample end-to-end를 실행한다.

금지:

- 오류를 숨기기 위한 광범위한 `try/except Exception: pass`
- 테스트 삭제 또는 assertion 약화
- API 키 하드코딩
- 사용자의 파일 삭제
- 실제 재현 없이 “수정했다”고 보고

마지막 보고:

- root cause
- 수정 파일과 핵심 변경
- 추가한 회귀테스트
- 실행한 명령
- 전체 테스트 결과
- 사용자가 다시 실행할 한 줄 명령
